# Approved Lessons

## L-001 — Evidence class must be explicit

Never present a private historical test result as a command reproducible from the public package.

## L-002 — Gate strength requires counterexamples

A successful checker is insufficient by itself. Representative privacy, structure, and integrity mutations must be rejected.

## L-003 — Publication remains a human decision

Automated scanning reduces risk but cannot certify screenshots, narration, or semantic disclosure.
